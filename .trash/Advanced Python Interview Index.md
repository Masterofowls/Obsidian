2. **Common answer** — solid spoken answer (correct, not just buzzwords)  
3. **Reference** — official docs, PEPs, or CPython docs (valid, citable)

## How to use in interviews

- Lead with the **correct model**, then **trade-offs** and **when you’d choose X**.
- For “did you use X in a project?” use **STAR** + your real metrics — start at [[Python Advanced - Practical Experience]].
- Cite **PEP / docs** only if asked for depth.
- Prefer **CPython** as the default implementation unless the job says otherwise.
