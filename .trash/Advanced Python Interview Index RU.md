# Advanced Python Interview Index (RU)

Заметки для **advanced / senior Python** в формате собеседования.

## Формат каждой карточки

1. **Вопрос** — типичный вопрос интервьюера  
2. **Типичный ответ** — корректный устный ответ (не только buzzwords)  
3. **Источник** — официальная документация, PEP, CPython docs

## Как отвечать на собеседовании

- Сначала **правильная модель**, затем **trade-offs** и **когда выберете X**.  
- PEP/docs — если просят глубину.  
- По умолчанию говорите про **CPython**, если не указано иное.  
- В «story»-вопросах используйте **STAR** и свои метрики/проекты.
