# Python Commands

## Running

```bash
python script.py
python -m module
python -c "print('hello')"
python -i script.py  # Interactive
```

## pip

```bash
pip install package
pip install -r requirements.txt
pip freeze > requirements.txt
pip show package
pip list
```

## venv

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```
