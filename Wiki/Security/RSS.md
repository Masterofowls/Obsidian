# What is RSS

## Overview
RSS (Really Simple Syndication) is a format for **distributing web content** in a standardized way.

## How It Works
1. Website publishes an **RSS feed** (XML file)
2. Feed contains: title, summary, link, date for each article
3. User subscribes with an **RSS reader**
4. Reader checks the feed periodically
5. New content appears in the reader automatically

## Benefits
- Follow many websites in one place
- No algorithm — see everything
- No tracking/ad targeting
- No social media account needed
