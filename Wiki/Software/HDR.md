# What is HDR

## Overview
HDR (High Dynamic Range) captures a **wider range of brightness and color** than standard content.

## SDR vs HDR
| Feature | SDR | HDR |
|---------|-----|-----|
| Brightness range | ~100 nits | ~1000+ nits |
| Color gamut | Rec. 709 | Rec. 2020 |
| Color depth | 8-bit (16.7M colors) | 10-bit (1.07B colors) |

## HDR Formats
| Format | Description |
|--------|-------------|
| HDR10 | Open standard, static metadata |
| HDR10+ | Dynamic metadata (per-scene) |
| Dolby Vision | Premium, dynamic metadata, up to 12-bit |
| HLG | Broadcast-friendly, backwards compatible |

## Benefits
- Brighter highlights, deeper shadows
- More vivid, lifelike colors
- More detail in both dark and bright scenes
