# What is SCRUM

## Overview
SCRUM is an **agile framework** for managing software development work in small, iterative cycles.

## Key Roles
- **Product Owner** — defines what to build (prioritized backlog)
- **Scrum Master** — facilitates the process, removes blockers
- **Development Team** — self-organizing team that does the work

## Artifacts
| Artifact | Description |
|----------|-------------|
| Product Backlog | List of all desired features |
| Sprint Backlog | Tasks for the current sprint |
| Increment | Working software delivered at sprint end |

## Sprint Cycle
1. **Sprint Planning** — Team selects items from backlog for the sprint (1-4 weeks)
2. **Daily Standup** — 15-minute daily meeting: What did I do? What will I do? Any blockers?
3. **Sprint Review** — Demo the increment to stakeholders
4. **Sprint Retrospective** — Team reflects on what went well and what to improve
