# How Blockchain Works

## Overview
Blockchain is a **distributed, immutable ledger** that records transactions across many computers.

## How It Works
1. A transaction is requested (e.g., send Bitcoin)
2. Transaction is broadcast to a **peer-to-peer network**
3. Network nodes **validate** the transaction
4. Verified transaction is combined with others into a **block**
5. Block is **cryptographically linked** to the previous block (chain)
6. Block is added to the chain — transaction is complete

## Key Properties
- **Decentralized**: No single authority controls it
- **Immutable**: Once a block is added, it cannot be altered
- **Transparent**: All transactions are publicly visible
- **Trustless**: No need to trust a central party

## Consensus Mechanisms
| Mechanism | How It Works |
|-----------|--------------|
| Proof of Work | Miners solve complex puzzles |
| Proof of Stake | Validators stake cryptocurrency |
| Proof of Authority | Pre-approved validators |
