# What is Bitrate

## Overview
Bitrate is the **amount of data processed per second**, measured in kbps (kilobits) or Mbps (megabits).

## How It Affects Quality
- Higher bitrate = more data = better quality
- Lower bitrate = less data = smaller file/lower quality

## Video Bitrate
| Resolution | Typical Bitrate |
|------------|-----------------|
| 720p | 2.5-5 Mbps |
| 1080p | 5-10 Mbps |
| 4K | 20-50 Mbps |

## Audio Bitrate
| Format | Quality |
|--------|---------|
| 128 kbps | Acceptable |
| 192 kbps | Good |
| 320 kbps | Excellent |
| 1411 kbps (CD) | Lossless |

## Variable vs Constant Bitrate
- **CBR**: Same bitrate throughout (predictable file size)
- **VBR**: Adjusts bitrate based on complexity (better quality/size ratio)
