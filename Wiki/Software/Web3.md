# How Web3 Works

## Overview
Web3 is a vision for a **decentralized internet** built on blockchain technology.

## Web Evolution
| Version | Era | Description |
|---------|-----|-------------|
| Web1 | 1990s | Static pages, read-only |
| Web2 | 2000s | Dynamic, user-generated content, platforms |
| Web3 | 2020s | Decentralized, user-owned, blockchain-based |

## Key Technologies
- **Smart Contracts** — self-executing code on blockchain
- **DApps** — decentralized applications (no central server)
- **DAOs** — decentralized autonomous organizations
- **NFTs** — unique digital ownership tokens
- **DeFi** — decentralized financial services
