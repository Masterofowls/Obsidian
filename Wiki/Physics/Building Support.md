# How Buildings Are Supported

## Overview
Buildings are supported by structural systems that transfer **loads** (weight, wind, seismic) to the ground.

## Basic Principles

### Load Path
1. Roof/floor loads → beams → columns → foundation → ground
2. Wind/seismic loads → walls/facade → frame → foundation → ground

### Structural Systems

| System | How It Works | Example |
|--------|--------------|---------|
| Frame | Columns + beams | Skyscrapers |
| Load-bearing walls | Walls carry the load | Houses, older buildings |
| Truss | Triangular elements | Bridges, roofs |
| Arch | Curves distribute force | Domes, bridges |
| Suspension | Cables carry tension | Bridges, roofs |

### Foundation Types
- **Shallow**: spread footings, slab (for stable soil)
- **Deep**: piles, caissons (for weak soil or heavy loads)
