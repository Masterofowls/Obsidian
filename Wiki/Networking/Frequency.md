# What is Frequency of Signal

## Overview
Frequency measures how many **cycles per second** a wave completes. Measured in **Hertz (Hz)**.

## Key Concepts
- **1 Hz** = one cycle per second
- **1 kHz** = 1,000 Hz
- **1 MHz** = 1,000,000 Hz
- **1 GHz** = 1,000,000,000 Hz

## Frequency Spectrum
| Range | Use |
|-------|-----|
| 50-60 Hz | Power lines |
| 88-108 MHz | FM radio |
| 470-890 MHz | TV broadcast |
| 900 MHz-6 GHz | Mobile/Wi-Fi |
| 2.4 GHz | Wi-Fi, Bluetooth |
| 5 GHz | Wi-Fi |
| 24-100 GHz | 5G mmWave |

## Higher Frequency = More Data
- More cycles per second → more data can be encoded
- But: higher frequencies have shorter range and worse penetration
