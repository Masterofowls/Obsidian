# What is RGB

## Overview
RGB is an **additive color model** where colors are created by mixing **Red, Green, and Blue** light.

## How It Works
- Each color channel: 0-255 (8 bits)
- Total colors: 256 × 256 × 256 = **16.7 million**
- (0, 0, 0) = black (no light)
- (255, 255, 255) = white (all light)

## Color Mixing
| Combination | Result |
|-------------|--------|
| Red + Green | Yellow |
| Red + Blue | Magenta |
| Green + Blue | Cyan |
| Red + Green + Blue | White |

## RGB vs CMYK
- **RGB** — screens (additive: light adds up)
- **CMYK** — printing (subtractive: ink absorbs light)
