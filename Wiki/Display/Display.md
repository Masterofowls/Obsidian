# How Displays Work

## Overview
A display converts **electrical signals into visible images**.

## LCD (Liquid Crystal Display)

### How It Works
1. **Backlight** provides white light
2. **Liquid crystals** twist/untwist when voltage is applied
3. Twisted crystals block light; untwisted crystals let light through
4. **Color filter** adds RGB sub-pixels
5. Each pixel = 3 sub-pixels (red, green, blue)

### Variants
- **IPS** — better color and viewing angles
- **VA** — better contrast
- **TN** — fast response time, cheaper

## OLED (Organic Light Emitting Diode)

### How It Works
- Each pixel is an **organic compound that emits light** when voltage is applied
- **No backlight needed**
- Pixels can turn completely off → perfect blacks
- Thinner, more flexible, better contrast

### Variants
- **AMOLED** — Active Matrix OLED (most phones)
- **MicroLED** — newer, brighter, no burn-in
