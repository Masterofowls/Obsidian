# How Circuits Work

## Overview
An electric circuit is a closed loop that allows electric current to flow, powering devices or performing computations.

## Basic Circuit Components
- **Voltage source** (battery, power supply) — pushes electrons
- **Conductors** (wires) — path for electrons
- **Load** (resistor, LED, motor) — uses the electrical energy
- **Switch** — opens/closes the circuit

## How Current Flows
1. Voltage source creates a **potential difference** (voltage)
2. This pushes electrons through the conductor
3. Electrons flow from **negative** to **positive** (conventional current: positive to negative)
4. The load converts electrical energy into work (light, heat, motion)

## Series vs Parallel

### Series
- Components connected end-to-end
- Same current flows through all
- If one breaks, circuit opens (all stop)

### Parallel
- Components connected side-by-side
- Same voltage across all
- If one breaks, others continue

## Ohm's Law
`V = I × R`
- Voltage = Current × Resistance
