# Все операции со строками в JavaScript

## Создание строк
1. **Литерал в одинарных кавычках** — `'text'`.
2. **Литерал в двойных кавычках** — `"text"`.
3. **Шаблонная строка (обратные кавычки)** — `` `text` `` — поддерживает интерполяцию и многострочность.
4. **String(значение)** — преобразование любого значения в строку.
5. **new String(значение)** — создаёт объект-обёртку String (редко используется).
6. **Сложение строк (`+`)** — конкатенация строк: `"a" + "b"` → `"ab"`.
7. **Сложение с присваиванием (`+=`)** — `str += "text"` добавляет в конец.
8. **Array.join(separator)** — объединяет массив в строку через разделитель.

## Методы доступа и поиска
9. **str.length** — длина строки (количество символов UTF-16).
10. **str[index]** — доступ к символу по индексу (например, `"abc"[1]` → `"b"`).
11. **str.charAt(index)** — возвращает символ по индексу (аналог `str[index]`).
12. **str.charCodeAt(index)** — возвращает Unicode (UTF-16) код символа.
13. **str.codePointAt(index)** — возвращает полный Unicode код символа (поддерживает суррогатные пары).
14. **str.at(index)** — возвращает символ по индексу (поддерживает отрицательные индексы, ES2022).
15. **str.indexOf(substring, fromIndex)** — индекс первого вхождения подстроки (или -1).
16. **str.lastIndexOf(substring, fromIndex)** — индекс последнего вхождения подстроки.
17. **str.includes(substring, fromIndex)** — проверяет, содержит ли строка подстроку (возвращает true/false).
18. **str.startsWith(substring, fromIndex)** — проверяет, начинается ли строка с подстроки.
19. **str.endsWith(substring, length)** — проверяет, заканчивается ли строка подстрокой.
20. **str.search(regexp)** — возвращает индекс первого совпадения с регулярным выражением (или -1).
21. **str.match(regexp)** — возвращает массив совпадений с регулярным выражением.
22. **str.matchAll(regexp)** — возвращает итератор со всеми совпадениями (ES2020).

## Методы извлечения подстрок
23. **str.slice(start, end)** — извлекает часть строки от `start` до `end` (не включая). Поддерживает отрицательные индексы.
24. **str.substring(start, end)** — извлекает часть строки. Не поддерживает отрицательные индексы (трактует как 0).
25. **str.substr(start, length)** — устаревший метод, извлекает `length` символов с позиции `start`.

## Методы преобразования регистра
26. **str.toUpperCase()** — преобразует всю строку в верхний регистр.
27. **str.toLowerCase()** — преобразует всю строку в нижний регистр.
28. **str.toLocaleUpperCase([locale])** — преобразует в верхний регистр с учётом локали.
29. **str.toLocaleLowerCase([locale])** — преобразует в нижний регистр с учётом локали.

## Методы замены и удаления
30. **str.replace(search, replacement)** — заменяет первое совпадение (строку или regexp).
31. **str.replaceAll(search, replacement)** — заменяет все совпадения (ES2021).
32. **str.trim()** — удаляет пробелы с обоих концов.
33. **str.trimStart() / str.trimLeft()** — удаляет пробелы в начале.
34. **str.trimEnd() / str.trimRight()** — удаляет пробелы в конце.
35. **str.padStart(targetLength, padString)** — дополняет строку слева до указанной длины.
36. **str.padEnd(targetLength, padString)** — дополняет строку справа до указанной длины.
37. **str.repeat(count)** — повторяет строку указанное количество раз.

## Методы разделения и объединения
38. **str.split(separator, limit)** — разбивает строку на массив по разделителю (строке или regexp).
39. **str.concat(str1, str2, ...)** — объединяет строки (альтернатива `+`).
40. **Array.join(separator)** — создаёт строку из массива (обратное действие к `split`).

## Сравнение и проверка
41. **str.localeCompare(compareString, locales, options)** — сравнивает строки с учётом локали. Возвращает -1, 0, 1.
42. **str === str2** — строгое сравнение строк.
43. **str == str2** — нестрогое сравнение строк.
44. **str >, <, >=, <=** — лексикографическое сравнение (по кодам символов).

## Преобразование и кодирование
45. **str.toString()** — возвращает примитив строки (для объектов-обёрток).
46. **str.valueOf()** — возвращает примитив строки.
47. **str.normalize([form])** — приводит строку к нормализованной форме Unicode (NFC, NFD, NFKC, NFKD).
48. **encodeURI(str)** — кодирует строку для URI (кроме специальных символов).
49. **encodeURIComponent(str)** — кодирует строку для URI-компонента (все специальные символы).
50. **decodeURI(str)** — декодирует URI.
51. **decodeURIComponent(str)** — декодирует URI-компонент.
52. **escape(str)** — устаревший метод кодирования (не рекомендуется).
53. **unescape(str)** — устаревший метод декодирования (не рекомендуется).

## Методы работы с Unicode
54. **String.fromCharCode(code1, code2, ...)** — создаёт строку из кодов UTF-16.
55. **String.fromCodePoint(code1, code2, ...)** — создаёт строку из полных кодов Unicode (поддерживает суррогатные пары).
56. **str.codePointAt(index)** — возвращает полный код символа Unicode.
57. **str.isWellFormed()** — проверяет, является ли строка валидным Unicode (ES2024).
58. **str.toWellFormed()** — заменяет некорректные суррогатные пары (ES2024).

## Конкатенация и интерполяция
59. **Шаблонная интерполяция** — `${выражение}` внутри шаблонных строк.
60. **Тегированные шаблоны** — вызов функции перед шаблонной строкой для кастомной обработки.
61. **Многострочные строки** — через шаблонные строки или перенос `\`.
62. **Экранирование символов** — `\n` (перенос), `\t` (таб), `\\` (обратный слэш), `\'`, `\"`, `\``.

## Регулярные выражения (String + RegExp)
63. **str.split(/regexp/)** — разбивает по регулярному выражению.
64. **str.search(/regexp/)** — ищет индекс совпадения с regexp.
65. **str.match(/regexp/)** — извлекает совпадения с regexp.
66. **str.matchAll(/regexp/g)** — итератор всех совпадений с regexp.
67. **str.replace(/regexp/, replacement)** — замена по regexp.
68. **str.replaceAll(/regexp/g, replacement)** — замена всех совпадений по regexp.
69. **RegExp.exec(str)** — выполнение регулярного выражения на строке.
70. **RegExp.test(str)** — проверяет, соответствует ли строка regexp.

## Свойства и методы объектов-обёрток
71. **String.prototype.constructor** — ссылка на функцию-конструктор.
72. **String.prototype.length** — длина строки.
73. **String.prototype[Symbol.iterator]** — делает строки итерируемыми (for...of).

## Операторы со строками
74. **typeof str** — возвращает `"string"` (для примитивов) или `"object"` (для объектов-обёрток).
75. **instanceof String** — проверяет, является ли объект экземпляром String.
76. **`in` оператор** — проверяет наличие свойства (например, `"length" in str`).
77. **Оператор `new`** — создаёт объект-обёртку String.
78. **Оператор `delete`** — удаляет свойства объекта-обёртки (бессмысленно для примитивов).

## Продвинутые операции
79. **Проверка на пустую строку** — `str === ""`, `!str`, `str.length === 0`.
80. **Проверка, содержит ли строка только пробелы** — `str.trim().length === 0`.
81. **Обрезка до длины** — `str.slice(0, maxLength)`.
82. **Обрезка до слова** — обрезать по последнему пробелу до `maxLength`.
83. **Извлечение последнего символа** — `str.at(-1)` или `str[str.length - 1]`.
84. **Переворот строки** — `str.split("").reverse().join("")`.
85. **Подсчёт вхождений подстроки** — `(str.match(/подстрока/g) || []).length`.
86. **Удаление всех пробелов** — `str.replace(/\s/g, "")`.
87. **Удаление повторяющихся пробелов** — `str.replace(/\s+/g, " ").trim()`.
88. **Капитализация (первая буква заглавная)** — `str[0].toUpperCase() + str.slice(1).toLowerCase()`.
89. **Преобразование в camelCase** — `str.replace(/([-_]\w)/g, g => g[1].toUpperCase())`.
90. **Преобразование в snake_case** — `str.replace(/[A-Z]/g, g => "_" + g.toLowerCase())`.
91. **Проверка на палиндром** — `str === str.split("").reverse().join("")`.
92. **Подсчёт символов (с учётом Unicode)** — `[...str].length` (а не `str.length` для суррогатов).
93. **Итерация по символам** — `for (let char of str) {}` (поддерживает суррогаты).
94. **Генерация случайной строки** — `Math.random().toString(36).slice(2, 10)`.
95. **Шифрование (base64)** — `btoa(str)` (браузер), `Buffer.from(str).toString("base64")` (Node.js).
96. **Декодирование base64** — `atob(str)` (браузер), `Buffer.from(str, "base64").toString()` (Node.js).
97. **Проверка на валидность JSON** — попытка `JSON.parse(str)`.
98. **Проверка, является ли строка числом** — `!isNaN(str) && !isNaN(parseFloat(str))`.
99. **Преобразование в массив символов** — `Array.from(str)` или `[...str]`.
100. **Сравнение строк без учёта регистра** — `str1.toLowerCase() === str2.toLowerCase()` или `str1.localeCompare(str2, undefined, { sensitivity: 'accent' }) === 0`.
