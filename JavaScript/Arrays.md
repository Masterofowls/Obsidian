# Все операции с массивами в JavaScript

## Создание массивов
1. **Литерал массива** — `[1, 2, 3]`.
2. **Конструктор Array()** — `new Array(1, 2, 3)` или `new Array(5)` (создаёт пустой массив длины 5).
3. **Array.from(iterable, mapFn, thisArg)** — создаёт массив из итерируемого объекта или псевдомассива.
4. **Array.of(...items)** — создаёт массив из аргументов (отличается от `Array()` при одном числе).
5. **Spread-оператор (`...`)** — `[...iterable]` создаёт массив из итерируемого объекта.
6. **Array.prototype.slice.call(arrayLike)** — создаёт массив из псевдомассива (устаревший способ).

## Свойства
7. **arr.length** — длина массива (количество элементов). Можно изменять для усечения/расширения.
8. **arr[Symbol.iterator]** — делает массивы итерируемыми (for...of).

## Методы добавления/удаления элементов
9. **arr.push(...items)** — добавляет элементы в конец. Возвращает новую длину.
10. **arr.pop()** — удаляет и возвращает последний элемент.
11. **arr.unshift(...items)** — добавляет элементы в начало. Возвращает новую длину.
12. **arr.shift()** — удаляет и возвращает первый элемент.
13. **arr.splice(start, deleteCount, ...items)** — изменяет массив: удаляет, вставляет или заменяет элементы.
14. **arr.slice(start, end)** — возвращает новый массив (копия части оригинального). Не изменяет оригинал.
15. **arr.concat(...items)** — объединяет массивы/значения в новый массив. Не изменяет оригинал.
16. **arr.copyWithin(target, start, end)** — копирует часть массива внутри самого себя. Изменяет оригинал.
17. **arr.fill(value, start, end)** — заполняет массив указанным значением. Изменяет оригинал.

## Методы поиска и проверки
18. **arr.indexOf(searchElement, fromIndex)** — индекс первого вхождения (или -1). Использует строгое сравнение.
19. **arr.lastIndexOf(searchElement, fromIndex)** — индекс последнего вхождения (или -1).
20. **arr.includes(searchElement, fromIndex)** — проверяет наличие элемента (возвращает true/false). Использует строгое сравнение.
21. **arr.find(callback, thisArg)** — возвращает первый элемент, удовлетворяющий условию (или undefined).
22. **arr.findIndex(callback, thisArg)** — возвращает индекс первого элемента, удовлетворяющего условию (или -1).
23. **arr.findLast(callback, thisArg)** — возвращает последний элемент, удовлетворяющий условию (ES2023).
24. **arr.findLastIndex(callback, thisArg)** — возвращает индекс последнего элемента, удовлетворяющего условию (ES2023).
25. **arr.some(callback, thisArg)** — проверяет, удовлетворяет ли хотя бы один элемент условию.
26. **arr.every(callback, thisArg)** — проверяет, удовлетворяют ли все элементы условию.

## Методы преобразования
27. **arr.map(callback, thisArg)** — создаёт новый массив, преобразуя каждый элемент.
28. **arr.filter(callback, thisArg)** — создаёт новый массив с элементами, прошедшими проверку.
29. **arr.reduce(callback, initialValue)** — свёртка массива слева направо (аккумулятор).
30. **arr.reduceRight(callback, initialValue)** — свёртка массива справа налево.
31. **arr.flat(depth)** — разворачивает вложенные массивы на указанную глубину (ES2019).
32. **arr.flatMap(callback, thisArg)** — сначала map, затем flat(1) (ES2019).
33. **arr.sort(compareFunction)** — сортирует массив (по умолчанию как строки). Изменяет оригинал.
34. **arr.reverse()** — переворачивает массив. Изменяет оригинал.

## Методы итерации (не возвращают новый массив)
35. **arr.forEach(callback, thisArg)** — выполняет функцию для каждого элемента.
36. **arr.keys()** — возвращает итератор по индексам.
37. **arr.values()** — возвращает итератор по значениям.
38. **arr.entries()** — возвращает итератор по парам [индекс, значение].
39. **arr[Symbol.iterator]()** — возвращает итератор по значениям (используется в for...of).

## Методы преобразования в строку
40. **arr.join(separator)** — объединяет элементы в строку через разделитель (по умолчанию `,`).
41. **arr.toString()** — преобразует массив в строку (эквивалентно `arr.join(',')`).
42. **arr.toLocaleString(locales, options)** — преобразует элементы в строку с учётом локали.
43. **arr.toSorted(compareFn)** — возвращает новый отсортированный массив (ES2023). Не изменяет оригинал.
44. **arr.toReversed()** — возвращает новый перевёрнутый массив (ES2023). Не изменяет оригинал.
45. **arr.toSpliced(start, deleteCount, ...items)** — возвращает новый массив с изменениями (ES2023).
46. **arr.with(index, value)** — возвращает новый массив с заменённым элементом по индексу (ES2023).

## Статические методы Array
47. **Array.isArray(value)** — проверяет, является ли значение массивом.
48. **Array.fromAsync(asyncIterable, mapFn, thisArg)** — создаёт массив из асинхронного итерируемого объекта (ES2025).
49. **Array.from()** — создаёт массив из итерируемого объекта.
50. **Array.of()** — создаёт массив из аргументов.

## Операторы с массивами
51. **`...` (spread)** — распаковывает массив в местах, где ожидаются элементы.
52. **`in` оператор** — проверяет наличие индекса: `2 in arr`.
53. **`delete arr[index]`** — удаляет элемент (оставляет пустой слот, длина не меняется).
54. **`new` оператор** — создаёт массив через конструктор.
55. **`instanceof Array`** — проверяет, является ли объект массивом (лучше `Array.isArray`).

## Сравнение массивов
56. **arr1 === arr2** — строгое сравнение ссылок (не содержимого).
57. **arr1 == arr2** — нестрогое сравнение ссылок.
58. **Сравнение содержимого** — `JSON.stringify(arr1) === JSON.stringify(arr2)`.
59. **Глубокое сравнение** — рекурсивная проверка всех элементов.
60. **Проверка на пустоту** — `arr.length === 0`.

## Проверки на массив
61. **`Array.isArray(arr)`** — лучший способ проверки.
62. **`arr instanceof Array`** — может дать ложный результат при работе с фреймами.
63. **`Object.prototype.toString.call(arr) === "[object Array]"`** — надёжная проверка.
64. **`typeof arr`** — возвращает `"object"` (не различает массивы и объекты).
65. **`Array.isArray(arr) && arr.length === 0`** — проверка на пустой массив.

## Работа с разреженными массивами
66. **Проверка на наличие элемента по индексу** — `index in arr`.
67. **Проверка на пропуски (дырки)** — `arr.hasOwnProperty(index)` или `Object.hasOwn(arr, index)`.
68. **Обход дырок** — `for...of` и `forEach` пропускают пустые слоты.
69. **Заполнение дырок** — `arr = Array.from(arr)` или `[...arr]`.

## Продвинутые операции
70. **Сумма элементов** — `arr.reduce((sum, x) => sum + x, 0)`.
71. **Максимальный элемент** — `Math.max(...arr)` или `arr.reduce((a, b) => Math.max(a, b))`.
72. **Минимальный элемент** — `Math.min(...arr)` или `arr.reduce((a, b) => Math.min(a, b))`.
73. **Удаление дубликатов** — `[...new Set(arr)]`.
74. **Пересечение массивов** — `arr1.filter(x => arr2.includes(x))`.
75. **Разность массивов** — `arr1.filter(x => !arr2.includes(x))`.
76. **Объединение массивов (с дубликатами)** — `[...arr1, ...arr2]` или `arr1.concat(arr2)`.
77. **Объединение массивов (без дубликатов)** — `[...new Set([...arr1, ...arr2])]`.
78. **Группировка элементов** — `arr.reduce((acc, x) => { acc[x] = (acc[x] || 0) + 1; return acc; }, {})`.
79. **Случайный элемент** — `arr[Math.floor(Math.random() * arr.length)]`.
80. **Перемешивание (shuffle)** — `arr.sort(() => Math.random() - 0.5)` (не идеально).
81. **Хорошее перемешивание** — алгоритм Фишера-Йетса.
82. **Чанкинг (разбивка на части)** — `arr.reduce((acc, _, i) => i % size === 0 ? [...acc, arr.slice(i, i + size)] : acc, [])`.
83. **Очередь (FIFO)** — `push` + `shift`.
84. **Стек (LIFO)** — `push` + `pop`.
85. **Двусторонняя очередь** — `unshift` + `pop` или `push` + `shift`.
86. **Плоское копирование (shallow copy)** — `[...arr]`, `arr.slice()`, `Array.from(arr)`.
87. **Глубокое копирование** — `JSON.parse(JSON.stringify(arr))` (только для JSON-безопасных данных).
88. **Структурированное клонирование** — `structuredClone(arr)`.
89. **Поиск максимальной длины слова** — `arr.reduce((max, str) => Math.max(max, str.length), 0)`.
90. **Фильтрация ложных значений** — `arr.filter(Boolean)`.
91. **Обратный вызов с индексом** — все методы принимают `(element, index, array)`.
92. **Привязка контекста (`thisArg`)** — второй параметр в методах (map, filter, forEach, find и др.).
93. **Изменение длины** — `arr.length = 0` (очистка массива).
94. **Проверка на массив массивов** — `arr.every(Array.isArray)`.
95. **Транспонирование матрицы** — `arr[0].map((_, i) => arr.map(row => row[i]))`.
96. **Преобразование в объект** — `Object.fromEntries(arr.entries())` или `Object.assign({}, arr)`.
97. **Преобразование в Map** — `new Map(arr.entries())`.
98. **Циклический сдвиг** — `arr.slice(n).concat(arr.slice(0, n))`.
99. **Поиск пересечения с условием** — `arr1.filter(x => arr2.some(y => y.id === x.id))`.
100. **Безопасный доступ** — `arr?.[index]` (опциональная цепочка) и `arr.at(index)`.
