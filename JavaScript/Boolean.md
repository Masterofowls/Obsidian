# Все операции с Boolean в JavaScript

## Создание булевых значений
1. **Литерал true** — `true`.
2. **Литерал false** — `false`.
3. **Boolean(значение)** — преобразует значение в boolean (явное приведение).
4. **new Boolean(значение)** — создаёт объект-обёртку Boolean (редко используется).
5. **Логические операторы** — возвращают булевы значения (`&&`, `||`, `!`).
6. **Операторы сравнения** — возвращают булевы значения (`===`, `>`, `<` и др.).

## Логические операторы (возвращают булевы)
7. **Логическое НЕ (`!`)** — инвертирует значение: `!true` → `false`, `!false` → `true`.
8. **Логическое И (`&&`)** — возвращает `true`, если оба операнда истинны.
9. **Логическое ИЛИ (`||`)** — возвращает `true`, если хотя бы один операнд истинен.
10. **Логическое И с присваиванием (`&&=`)** — `x &&= y` → если `x` истинно, присваивает `y`.
11. **Логическое ИЛИ с присваиванием (`||=`)** — `x ||= y` → если `x` ложно, присваивает `y`.
12. **Нулевое слияние с присваиванием (`??=`)** — `x ??= y` → если `x` null/undefined, присваивает `y`.

## Операторы сравнения (возвращают boolean)
13. **Строгое равенство (`===`)** — `true` если значения равны и одного типа.
14. **Строгое неравенство (`!==`)** — `true` если значения не равны или разных типов.
15. **Нестрогое равенство (`==`)** — `true` если значения равны после приведения типов.
16. **Нестрогое неравенство (`!=`)** — `true` если значения не равны после приведения типов.
17. **Больше (`>`)** — `true` если левый операнд больше правого.
18. **Больше или равно (`>=`)** — `true` если левый операнд больше или равен правому.
19. **Меньше (`<`)** — `true` если левый операнд меньше правого.
20. **Меньше или равно (`<=`)** — `true` если левый операнд меньше или равен правому.
21. **`instanceof`** — `true` если объект является экземпляром класса.
22. **`in`** — `true` если свойство существует в объекте.
23. **Оператор `typeof`** — возвращает строку (не boolean, но используется в проверках).

## Ложные (Falsy) значения (6 штук)
24. **`false`** — логическое ложное значение.
25. **`0`** — число ноль (и `-0`).
26. **`""`** — пустая строка (и `''`, ` `` `).
27. **`null`** — отсутствие значения.
28. **`undefined`** — неопределённое значение.
29. **`NaN`** — "не число".
30. **Все остальные значения** — истинные (truthy), включая пустые массивы `[]`, пустые объекты `{}`, строку `" "` (с пробелом).

## Проверки на булевы значения
31. **`typeof value === "boolean"`** — проверка, является ли значение булевым примитивом.
32. **`value instanceof Boolean`** — проверка, является ли объект-обёрткой Boolean.
33. **`Object.prototype.toString.call(value) === "[object Boolean]"`** — проверка на boolean (примитив или объект).
34. **`Boolean(value) === value`** — проверка, является ли value булевым примитивом (не сработает для обёртки).
35. **`value === true || value === false`** — проверка на булев примитив.

## Преобразование в Boolean (явное и неявное)
36. **`Boolean(value)`** — явное преобразование в boolean.
37. **`!!value`** — двойное отрицание (явное преобразование, короткая запись).
38. **`value ? true : false`** — тернарный оператор (явное преобразование).
39. **`if (value) {}`** — неявное преобразование в условии.
40. **`while (value) {}`** — неявное преобразование в цикле.
41. **`do {} while (value)`** — неявное преобразование в цикле.
42. **`for (; value; ) {}`** — неявное преобразование в цикле.
43. **`value && expression`** — неявное преобразование (короткое замыкание).
44. **`value || expression`** — неявное преобразование (короткое замыкание).
45. **`!value`** — неявное преобразование (инвертирует).
46. **`value &&= y`** — неявное преобразование.
47. **`value ||= y`** — неявное преобразование.
48. **`value ??= y`** — неявная проверка на null/undefined (не на boolean!).

## Методы и свойства Boolean
49. **`Boolean.prototype.toString()`** — возвращает строку `"true"` или `"false"`.
50. **`Boolean.prototype.valueOf()`** — возвращает примитив `true` или `false`.
51. **`Boolean.prototype.constructor`** — ссылка на функцию-конструктор.
52. **`Boolean.prototype[Symbol.toStringTag]`** — возвращает `"Boolean"` (для `Object.prototype.toString`).

## Логические операции с коротким замыканием
53. **`&&` (короткое замыкание)** — если левый операнд ложный, возвращает его; иначе возвращает правый.
54. **`||` (короткое замыкание)** — если левый операнд истинный, возвращает его; иначе возвращает правый.
55. **`??` (нулевое слияние, не булево)** — возвращает правый операнд, если левый `null` или `undefined`.
56. **`&&=` (короткое замыкание)** — присваивает только если левый операнд истинный.
57. **`||=` (короткое замыкание)** — присваивает только если левый операнд ложный.

## Сравнение Boolean с другими типами
58. **`true == 1`** → `true` (нестрогое сравнение).
59. **`false == 0`** → `true` (нестрогое сравнение).
60. **`true === 1`** → `false` (строгое сравнение).
61. **`false === 0`** → `false` (строгое сравнение).
62. **`true == "1"`** → `true` (нестрогое сравнение).
63. **`false == ""`** → `true` (нестрогое сравнение).
64. **`true === "1"`** → `false` (строгое сравнение).
65. **`false === ""`** → `false` (строгое сравнение).
66. **`true == "true"`** → `false` (строки не преобразуются в булевы для сравнения).
67. **`false == "false"`** → `false` (строки не преобразуются в булевы для сравнения).
68. **`Boolean("true")`** → `true` (непустая строка).
69. **`Boolean("false")`** → `true` (непустая строка).

## Логические операции над числами
70. **`!0`** → `true` (0 — ложное значение).
71. **`!!0`** → `false` (0 — ложное).
72. **`!1`** → `false` (1 — истинное).
73. **`!!1`** → `true` (1 — истинное).
74. **`!NaN`** → `true` (NaN — ложное).
75. **`!!NaN`** → `false` (NaN — ложное).
76. **`!null`** → `true` (null — ложное).
77. **`!!null`** → `false` (null — ложное).
78. **`!undefined`** → `true` (undefined — ложное).
79. **`!!undefined`** → `false` (undefined — ложное).
80. **`!""`** → `true` (пустая строка — ложная).
81. **`!!""`** → `false` (пустая строка — ложная).
82. **`!" "`** → `false` (строка с пробелом — истинная).
83. **`!!" "`** → `true` (строка с пробелом — истинная).
84. **`![]`** → `false` (пустой массив — истинный).
85. **`!![]`** → `true` (пустой массив — истинный).
86. **`!{}`** → `false` (пустой объект — истинный).
87. **`!!{}`** → `true` (пустой объект — истинный).

## Побитовые операции (возвращают число, не boolean)
88. **`~x`** — побитовое НЕ (возвращает число, но может использоваться для проверки `-1`).
89. **`x & y`** — побитовое И (возвращает число).
90. **`x | y`** — побитовое ИЛИ (возвращает число).
91. **`x ^ y`** — побитовое XOR (возвращает число).
92. **`x << y`** — сдвиг влево (возвращает число).
93. **`x >> y`** — сдвиг вправо (возвращает число).
94. **`x >>> y`** — сдвиг вправо с заполнением нулями (возвращает число).

## Продвинутые булевы операции
95. **Исключающее ИЛИ (XOR) для булевых** — `(a || b) && !(a && b)` или `a !== b`.
96. **Импликация (a → b)** — `!a || b`.
97. **Эквивалентность (a ↔ b)** — `a === b`.
98. **Проверка на вхождение в диапазон** — `x >= min && x <= max`.
99. **Проверка, что все элементы истинны** — `array.every(Boolean)`.
100. **Проверка, что хотя бы один элемент истинен** — `array.some(Boolean)`.
