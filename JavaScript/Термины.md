
## Типы данных (8)
1. **Number** — целые и дробные числа, включая NaN, Infinity и -Infinity.
2. **String** — строки (примитив, неизменяемы). Создаются через кавычки или шаблонные строки.
3. **Boolean** — логический тип: `true` или `false`.
4. **Null** — намеренное отсутствие значения. `typeof null` возвращает `"object"` (исторический баг).
5. **Undefined** — значение не присвоено. Переменная объявлена, но не инициализирована.
6. **Symbol** — уникальный и неизменяемый примитив (ES6). Используется как ключи свойств объектов.
7. **BigInt** — числа произвольной точности (за пределами 2⁵³). Создаются через суффикс `n`.
8. **Object** — ссылочный тип. Включает массивы, функции, даты, регулярные выражения и null-подобные объекты.

## Операторы (15)
9. **Арифметические** — `+ - * / % ** ++ --`. Выполняют математические операции.
10. **Сравнения** — `== === != !== > < >= <=`. Возвращают `true`/`false`. `===` сравнивает без приведения типов.
11. **Логические** — `&& || !`. Работают с булевыми значениями, поддерживают короткое замыкание.
12. **Побитовые** — `& | ^ ~ << >> >>>`. Работают на уровне битов (32-битные целые).
13. **Присваивания** — `= += -= *= /=`. Присваивают значение переменной.
14. **Тернарный** — `условие ? выражение1 : выражение2`. Условный оператор.
15. **Опциональная цепочка** — `?.`. Безопасный доступ к вложенным свойствам (возвращает `undefined` при null/undefined).
16. **Нулевое слияние** — `??`. Возвращает правый операнд, если левый — `null` или `undefined`.
17. **Оператор запятая** — `,`. Выполняет несколько выражений, возвращает последнее.
18. **typeof** — возвращает строку с типом операнда.
19. **instanceof** — проверяет, принадлежит ли объект классу (по цепочке прототипов).
20. **delete** — удаляет свойство объекта. Возвращает `true`/`false`.
21. **in** — проверяет наличие свойства в объекте или индекса в массиве.
22. **new** — создаёт экземпляр объекта через конструктор.
23. **void** — вычисляет выражение и возвращает `undefined`.

## Области видимости и переменные (6)
24. **Глобальная область** — доступна везде. В браузере — `window`, в Node.js — `global`.
25. **Функциональная область** — создаётся внутри функции. Доступна только внутри неё (`var`, `function`).
26. **Блочная область** — создаётся внутри `{}` для `let` и `const`.
27. **Лексическое окружение** — внутренняя структура движка, хранящая переменные текущей области.
28. **Всплытие (Hoisting)** — поднятие объявлений переменных/функций в начало области до выполнения кода.
29. **Временная мёртвая зона (TDZ)** — недоступность `let`/`const` до строки инициализации.

## Функции и замыкания (10)
30. **Function Declaration** — объявление функции через `function name() {}`. Всплывает полностью.
31. **Function Expression** — присвоение функции переменной: `const fn = function() {}`. Не всплывает.
32. **Стрелочная функция** — `() => {}`. Нет собственного `this`, `arguments` и не может быть конструктором.
33. **Замыкание (Closure)** — функция, запоминающая внешнюю область видимости даже после её завершения.
34. **IIFE (Immediately Invoked Function Expression)** — функция, выполняемая сразу после создания: `(function(){})()`.
35. **Чистая функция** — функция без побочных эффектов, возвращающая одинаковый результат для одинаковых аргументов.
36. **Функция высшего порядка** — принимает другую функцию как аргумент или возвращает функцию.
37. **Колбэк** — функция, переданная как аргумент и вызываемая позже.
38. **Каррирование** — преобразование `f(a, b, c)` в `f(a)(b)(c)`.
39. **Частичное применение** — фиксация части аргументов функции с возвратом новой функции.

## Объекты и ООП (12)
40. **Литерал объекта** — `{ key: value }`. Базовый способ создания объектов.
41. **Прототип** — скрытая ссылка `[[Prototype]]`, через которую объекты наследуют свойства.
42. **Прототипное наследование** — цепочка прототипов для делегирования свойств и методов.
43. **Класс (ES6)** — синтаксический сахар над прототипами. Объявляется через `class`.
44. **Конструктор** — специальный метод `constructor()` в классе или функция с `new`.
45. **Статические методы** — методы класса, вызываемые без создания экземпляра (`static`).
46. **Геттеры/Сеттеры** — `get`/`set` для контроля доступа к свойствам.
47. **Инкапсуляция** — скрытие внутреннего состояния (через замыкания или приватные поля `#`).
48. **Полиморфизм** — один интерфейс для разных типов (утиная типизация).
49. **Абстракция** — скрытие деталей реализации, предоставление простого API.
50. **Миксины** — примеси функциональности через композицию или `Object.assign()`.
51. **Приватные поля** — `#field`. Доступны только внутри класса (ES2022).

## Коллекции (5)
52. **Массив** — упорядоченный список элементов с числовыми индексами и свойством `length`.
53. **Map** — коллекция ключ-значение. Ключи могут быть любого типа (в отличие от объектов).
54. **Set** — коллекция уникальных значений любого типа.
55. **WeakMap** — Map со слабыми ссылками на ключи-объекты. Не мешает сборке мусора.
56. **WeakSet** — Set со слабыми ссылками на объекты.

## Строки и регулярки (3)
57. **Шаблонные строки** — обратные кавычки `` ` `` с интерполяцией `${}` и поддержкой многострочности.
58. **Тегированные шаблоны** — вызов функции перед шаблонной строкой для кастомной обработки.
59. **Регулярные выражения** — объект `RegExp` для поиска и замены по шаблону.

## Асинхронность (13)
60. **Синхронный код** — выполняется последовательно, блокируя поток.
61. **Асинхронный код** — выполняется без блокировки (таймеры, сетевые запросы, события).
62. **Колбэк-ад (Callback Hell)** — глубоко вложенные колбэки, усложняющие чтение кода.
63. **Promise** — объект, представляющий результат асинхронной операции. Состояния: `pending`, `fulfilled`, `rejected`.
64. **then/catch/finally** — методы Promise для обработки результатов и ошибок.
65. **Promise.all** — ждёт выполнения всех Promise. Возвращает массив результатов.
66. **Promise.race** — возвращает результат первого завершённого Promise.
67. **Promise.allSettled** — ждёт все Promise, игнорируя ошибки. Возвращает статусы.
68. **Promise.any** — возвращает первый успешно выполненный Promise.
69. **async/await** — синтаксический сахар над Promise для написания асинхронного кода в синхронном стиле.
70. **Event Loop** — бесконечный цикл, обрабатывающий очередь задач (микро- и макрозадачи).
71. **Микрозадачи** — задачи с высоким приоритетом (Promise.then, queueMicrotask, MutationObserver).
72. **Макрозадачи** — задачи с низким приоритетом (setTimeout, setInterval, I/O, рендеринг).

## Ошибки и отладка (5)
73. **try...catch...finally** — конструкция для перехвата и обработки исключений.
74. **throw** — оператор для генерации пользовательской ошибки.
75. **Error / TypeError / SyntaxError / ReferenceError** — встроенные классы ошибок.
76. **Стек вызовов (Call Stack)** — структура данных, хранящая последовательность вызовов функций.
77. **debugger** — ключевое слово для установки точки останова в коде.

## Модули (3)
78. **ES Modules** — система модулей с `import`/`export`. Работает в браузерах и Node.js (ESM).
79. **CommonJS** — модульная система Node.js с `require()` и `module.exports`.
80. **globalThis** — универсальный глобальный объект, работающий в любой среде.

## Память и производительность (4)
81. **Сборка мусора** — автоматическое освобождение памяти от неиспользуемых объектов (алгоритм достижимости).
82. **Утечка памяти** — ситуация, когда объекты не удаляются из-за забытых ссылок (таймеры, замыкания, глобальные переменные).
83. **WeakRef** — слабая ссылка на объект, не препятствующая сборке мусора.
84. **FinalizationRegistry** — механизм для вызова колбэка после удаления объекта сборщиком мусора.

## Продвинутые концепции (16)
85. **Декораторы** — (ES2022+) специальные функции для изменения классов и их членов (`@decorator`).
86. **Proxy** — объект-обёртка, перехватывающий операции над целевым объектом (get, set, delete и др.).
87. **Reflect** — встроенный объект с методами для перехвата (используется в паре с Proxy).
88. **Итератор** — объект с методом `next()`, возвращающим `{ value, done }`.
89. **Генератор** — функция `function*`, возвращающая итератор и использующая `yield` для приостановки.
90. **Асинхронный генератор** — `async function*` с `for await...of` и асинхронным `yield`.
91. **Приведение типов** — преобразование одного типа в другой: явное (`Number()`) и неявное (`+`).
92. **NaN (Not-a-Number)** — числовое значение, обозначающее "не число". Проверяется через `isNaN()`.
93. **Строгое (`===`) vs нестрогое (`==`) сравнение** — `===` сравнивает без приведения типов, `==` приводит типы.
94. **Spread-оператор** — `...` распаковывает массив/объект в местах, где ожидаются элементы или свойства.
95. **Деструктуризация** — распаковка значений из массивов или свойств объектов в переменные.
96. **Rest-параметры** — `...args` в параметрах функции собирает оставшиеся аргументы в массив.
97. **defineProperty** — метод `Object.defineProperty()` для настройки свойств (геттеры, сеттеры, дескрипторы).
98. **Дескрипторы свойств** — атрибуты: `value`, `writable`, `enumerable`, `configurable`, `get`, `set`.
99. **ArrayBuffer / TypedArray** — буферы для работы с бинарными данными (Int8Array, Float64Array и др.).
100. **Atomics / SharedArrayBuffer** — для потокобезопасной работы с разделяемой памятью в многопоточных окружениях.
