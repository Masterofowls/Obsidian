# Все операции с функциями в JavaScript

## Объявление функций
1. **Function Declaration** — `function name(params) { }` (всплывает полностью).
2. **Function Expression** — `const fn = function(params) { }` (не всплывает).
3. **Стрелочная функция (Arrow)** — `(params) => { }` или `params => expression` (нет `this` и `arguments`).
4. **Анонимная функция** — функция без имени: `function() { }`.
5. **Именованное функциональное выражение** — `const fn = function named() { }` (имя доступно внутри).
6. **Конструктор Function()** — `new Function('param', 'return param * 2')` (создаёт из строки, не рекомендуется).
7. **Метод объекта** — `{ method() { } }` (сокращённая запись).
8. **Генератор (Generator)** — `function* name() { yield value; }`.
9. **Асинхронная функция (Async)** — `async function name() { }`.
10. **Асинхронный генератор** — `async function* name() { yield value; }`.
11. **Класс-метод** — `class { method() { } }` (включая `static` и `async`).
12. **Геттеры/Сеттеры** — `{ get prop() { }, set prop(val) { } }`.

## Параметры и аргументы
13. **Обязательные параметры** — `function fn(a, b) { }`.
14. **Параметры по умолчанию** — `function fn(a = 10, b = "text") { }`.
15. **Rest-параметры** — `function fn(...args) { }` (собирает все аргументы в массив).
16. **Аргументы (arguments)** — `arguments` (псевдомассив, доступен только в обычных функциях, не в стрелочных).
17. **Деструктуризация параметров** — `function fn({ a, b }) { }` или `function fn([a, b]) { }`.
18. **Деструктуризация с умолчаниями** — `function fn({ a = 1, b = 2 } = {}) { }`.
19. **Параметр как функция (колбэк)** — `function fn(callback) { callback(); }`.

## Вызов функций
20. **Обычный вызов** — `fn(arg1, arg2)`.
21. **Вызов как метод** — `obj.method()` (`this` = `obj`).
22. **Вызов как конструктор** — `new Constructor()` (создаёт экземпляр).
23. **Косвенный вызов через `call()`** — `fn.call(context, arg1, arg2)` (задаёт `this`).
24. **Косвенный вызов через `apply()`** — `fn.apply(context, [arg1, arg2])` (аргументы массивом).
25. **Вызов с привязкой через `bind()`** — `const boundFn = fn.bind(context, arg1)` (возвращает новую функцию).
26. **Немедленный вызов (IIFE)** — `(function() { })()` или `(() => { })()`.
27. **Вызов через `new.target`** — проверка, вызвана ли функция с `new`.
28. **Вызов через `toString()`** — `fn.toString()` (возвращает строку кода функции).

## Свойства функций
29. **`fn.name`** — имя функции (или анонимная строка).
30. **`fn.length`** — количество объявленных параметров (не считая rest).
31. **`fn.prototype`** — объект прототипа для функций-конструкторов.
32. **`fn.constructor`** — ссылка на конструктор Function.
33. **`fn.toString()`** — строковое представление кода функции.
34. **`fn[Symbol.hasInstance]`** — кастомная проверка `instanceof`.
35. **`fn[Symbol.toStringTag]`** — возвращает `"Function"` (для `Object.prototype.toString`).

## Методы функций (Function.prototype)
36. **`fn.call(thisArg, arg1, arg2, ...)`** — вызывает функцию с заданным `this` и аргументами.
37. **`fn.apply(thisArg, [argsArray])`** — вызывает функцию с заданным `this` и аргументами-массивом.
38. **`fn.bind(thisArg, arg1, arg2, ...)`** — возвращает новую функцию с привязанным `this` и аргументами.
39. **`fn.toString()`** — возвращает код функции (включая комментарии).
40. **`fn.valueOf()`** — возвращает саму функцию (примитив).

## Контекст (this)
41. **Глобальный `this`** — в браузере `window`, в Node.js `global`, в strict mode `undefined`.
42. **`this` в обычной функции** — зависит от способа вызова (глобальный, метод, конструктор).
43. **`this` в стрелочной функции** — лексический (берёт из внешней области, не переопределяется).
44. **`this` в методе объекта** — ссылается на объект.
45. **`this` в конструкторе** — ссылается на создаваемый экземпляр.
46. **`this` в обработчиках событий** — ссылается на элемент (в обычной функции).
47. **`this` в обработчиках (стрелочная)** — берёт из внешней области.
48. **Потеря `this`** — когда функция передаётся как колбэк без привязки.
49. **Привязка `this` через `bind`** — `fn.bind(obj)`.
50. **Привязка `this` через `call/apply`** — временная привязка при вызове.

## Замыкания (Closure)
51. **Замыкание** — функция, запоминающая внешнюю область видимости после её завершения.
52. **Сохранение переменных** — внутренняя функция имеет доступ к переменным внешней.
53. **Счётчики через замыкание** — функция, возвращающая другую функцию с приватной переменной.
54. **Мемоизация через замыкание** — кэширование результатов внутри функции.
55. **Приватные методы** — через замыкание в модульном паттерне.

## Функции высшего порядка
56. **Принимает функцию как аргумент** — `array.map(fn)`, `array.filter(fn)`.
57. **Возвращает функцию** — `function makeCounter() { return () => {} }`.
58. **Композиция функций** — `const compose = (f, g) => x => f(g(x))`.
59. **Каррирование** — `f(a, b)` → `f(a)(b)`.
60. **Частичное применение** — фиксация части аргументов, возврат новой функции.

## Каррирование и частичное применение
61. **Каррирование вручную** — `function curry(f) { return (a) => (b) => f(a, b); }`.
62. **Частичное применение через bind** — `fn.bind(null, arg1)`.
63. **Автоматическое каррирование** — библиотека `lodash.curry`.
64. **Обратное каррирование** — `f(a)(b)(c)` → `f(a, b, c)`.

## Генераторы
65. **Объявление** — `function* gen() { yield 1; yield 2; }`.
66. **Вызов** — `const it = gen()` (возвращает итератор).
67. **`yield`** — приостанавливает выполнение и возвращает значение.
68. **`yield*`** — делегирует итерацию другому генератору или итерируемому объекту.
69. **`next(value)`** — возобновляет выполнение, возвращает `{ value, done }`.
70. **`return(value)`** — завершает генератор.
71. **`throw(error)`** — выбрасывает ошибку внутри генератора.
72. **Использование в `for...of`** — `for (const val of gen()) { }`.
73. **Генераторы как наблюдатели** — `next(value)` передаёт значение обратно.
74. **Асинхронные генераторы** — `async function* gen() { await delay(); yield value; }`.
75. **`for await...of`** — итерация по асинхронному генератору.

## Асинхронные функции (async/await)
76. **Объявление** — `async function fn() { }`.
77. **Возвращаемое значение** — всегда возвращает Promise.
78. **`await`** — приостанавливает выполнение до разрешения Promise.
79. **Обработка ошибок** — `try...catch` внутри `async` функции.
80. **Асинхронное IIFE** — `(async () => { await something(); })()`.
81. **Асинхронные методы** — `{ async method() { } }`.
82. **`await` в верхнем уровне** — (ES2022) поддерживается в модулях.
83. **`Promise.all` + `async`** — параллельное выполнение.
84. **Цепочки `await`** — `const result = await fn1(await fn2())`.

## Операторы с функциями
85. **`new` оператор** — создаёт экземпляр через функцию-конструктор.
86. **`instanceof Function`** — проверяет, является ли объект функцией.
87. **`typeof fn`** — возвращает `"function"`.
88. **`delete fn.prop`** — удаляет свойство функции.
89. **`in` оператор** — проверяет наличие свойства в функции.
90. **`...` (spread) с аргументами** — `fn(...array)` (распаковывает массив).
91. **`...` (rest) в параметрах** — `function fn(...args) { }`.

## Проверки
92. **`typeof fn === "function"`** — проверка, является ли значение функцией.
93. **`fn instanceof Function`** — проверка через конструктор.
94. **`Object.prototype.toString.call(fn) === "[object Function]"`** — надёжная проверка.
95. **Проверка на стрелочную функцию** — `fn.prototype === undefined` (не всегда точно).
96. **Проверка на генератор** — `fn.constructor.name === "GeneratorFunction"`.
97. **Проверка на асинхронную** — `fn.constructor.name === "AsyncFunction"`.
98. **Проверка на конструктор** — `fn.prototype && fn.prototype.constructor === fn`.

## Продвинутые операции
99. **Рекурсия** — функция, вызывающая саму себя.
100. **Хвостовая рекурсия** — оптимизация в строгом режиме (в некоторых движках).
101. **Декораторы** — `@decorator` (ES2022+) для классов и методов.
102. **Мемоизация** — кэширование результатов функции.
103. **Троттлинг (throttle)** — ограничение частоты вызовов.
104. **Дебонсинг (debounce)** — отложенный вызов после паузы.
105. **Один раз (once)** — функция, выполняющаяся только один раз.
106. **Композиция функций** — `pipe(f1, f2, f3)` (выполняет последовательно).
107. **Библиотечные инструменты** — `lodash.flow`, `ramda.compose`.
108. **Полиморфизм функций** — одна функция ведёт себя по-разному для разных типов.
109. **Перегрузка функций** — в JS нет встроенной, можно эмулировать через проверку типов.
110. **Функция как объект** — функции могут иметь свои свойства и методы.
111. **Функция с кэшем (мемоизация через объект)** — `fn.cache = {}`.
112. **Сохранение состояния в функции** — через замыкание или свойства функции.
113. **Ленивые вычисления** — функция, вычисляющая результат только при необходимости.
114. **Паттерн "Модуль" (Module Pattern)** — IIFE + замыкание для приватных переменных.
115. **Паттерн "Одиночка" (Singleton)** — функция, возвращающая единственный экземпляр.
116. **Фабричная функция** — функция, возвращающая новый объект.
117. **Функция-обёртка (Wrapper)** — функция, добавляющая поведение к другой функции.
118. **Автоматическая обработка ошибок** — `tryCatchWrapper(fn)`.
119. **Логирование вызовов** — `withLogging(fn)`.
120. **Измерение времени выполнения** — `withTiming(fn)`.

## Специальные вызовы
121. **`Function.prototype.call.bind(fn, context)`** — создаёт функцию с привязанным `this`.
122. **`Function.prototype.apply.bind(fn, context)`** — аналогично для `apply`.
123. **`new Function('return ' + expression)()`** — кастомный eval (опасно, не использовать).
124. **`eval()`** — выполняет строку как код (опасно, избегать).
125. **`setTimeout(fn, delay)`** — вызов функции с задержкой.
126. **`setInterval(fn, interval)`** — периодический вызов.
127. **`requestAnimationFrame(fn)`** — вызов перед следующим рендерингом (браузер).
128. **`queueMicrotask(fn)`** — вызов в микрозадаче (высокий приоритет).
129. **`Promise.then(fn)`** — вызов после разрешения Promise.
130. **`Promise.catch(fn)`** — вызов при ошибке в Promise.
131. **`Promise.finally(fn)`** — вызов всегда после Promise.
132. **`Array.prototype.reduce(fn, acc)`** — свёртка массива с функцией.
133. **`Array.prototype.sort(fn)`** — сортировка с компаратором.
134. **`Array.prototype.forEach(fn)`** — итерация с функцией.

## Производительность
135. **Оптимизация рекурсии** — использование хвостовой рекурсии.
136. **Избегание создания функций в циклах** — выносить за цикл.
137. **Использование стрелочных функций для коротких выражений** — `x => x * 2`.
138. **Кэширование результатов** — мемоизация для тяжёлых вычислений.
139. **Асинхронная обработка больших данных** — через `async/await` и чанкинг.
140. **Web Workers** — выполнение функций в отдельном потоке.

## Безопасность
141. **Ограничение контекста** — `fn.bind(null)` для изоляции.
142. **Строгий режим (`"use strict"`)** — меняет поведение `this`, запрещает небезопасные операции.
143. **Избегание `eval` и `new Function`** — из-за уязвимостей.
144. **Проверка входных параметров** — валидация типов и значений.
145. **Санация колбэков** — проверка, что переданный аргумент — функция.

## Отладка
146. **`console.log(fn)`** — вывод кода функции.
147. **`console.dir(fn)`** — вывод свойств функции.
148. **`debugger`** — точка останова внутри функции.
149. **`fn.name`** — помогает в отладке (автоматическое имя).
150. **`Error.stack`** — стек вызовов функции.
