# Асинхронность (Asynchronous Programming) в JavaScript

## Базовые понятия
1. **Синхронный код** — выполняется последовательно, каждая операция блокирует выполнение следующей.
2. **Асинхронный код** — выполняется без блокировки основного потока (таймеры, запросы, события).
3. **Однопоточность** — JavaScript имеет один главный поток выполнения (call stack).
4. **Неблокирующий ввод-вывод** — операции ввода-вывода выполняются асинхронно, не блокируя поток.
5. **Параллелизм** — одновременное выполнение нескольких задач (Web Workers).
6. **Конкурентность** — чередование выполнения задач на одном потоке.

## Event Loop (Цикл событий)
7. **Event Loop** — бесконечный цикл, управляющий выполнением асинхронного кода.
8. **Call Stack (Стек вызовов)** — структура данных, хранящая выполняемые функции (LIFO).
9. **Callback Queue (Очередь колбэков)** — очередь задач, ожидающих выполнения (FIFO).
10. **Microtask Queue (Очередь микрозадач)** — очередь с более высоким приоритетом.
11. **Macrotask Queue (Очередь макрозадач)** — очередь с низким приоритетом (также Task Queue).
12. **Event Loop алгоритм** — 1) выполнить стек, 2) обработать микрозадачи, 3) взять макрозадачу.
13. **Рендеринг (браузер)** — происходит между макрозадачами (но после микрозадач).

## Callback (Колбэки)
14. **Колбэк (Callback)** — функция, передаваемая как аргумент для вызова позже.
15. **Асинхронный колбэк** — функция, вызываемая после завершения асинхронной операции.
16. **Обработка ошибок в колбэках** — первый аргумент ошибка (error-first callback).
17. **Колбэк-ад (Callback Hell)** — глубоко вложенные колбэки, усложняющие код.
18. **Решение колбэк-ада** — использование Promise, async/await, модульность.
19. **Колбэки в событиях** — `element.addEventListener('click', callback)`.
20. **Колбэки в таймерах** — `setTimeout(callback, delay)`.

## Таймеры
21. **setTimeout(callback, delay, ...args)** — выполняет колбэк через указанное время (мс).
22. **setInterval(callback, interval, ...args)** — выполняет колбэк периодически с указанным интервалом.
23. **clearTimeout(timeoutId)** — отменяет выполнение setTimeout.
24. **clearInterval(intervalId)** — отменяет выполнение setInterval.
25. **setImmediate(callback)** — выполняется в Node.js после текущего цикла событий (макрозадача).
26. **queueMicrotask(callback)** — помещает задачу в очередь микрозадач (ES2021).
27. **requestAnimationFrame(callback)** — выполняется перед следующим рендерингом (браузер).
28. **requestIdleCallback(callback)** — выполняется в свободное время (браузер).

## Promise (Промисы)
29. **Promise** — объект, представляющий результат асинхронной операции.
30. **Состояния Promise** — `pending` (ожидание), `fulfilled` (выполнено успешно), `rejected` (ошибка).
31. **Создание Promise** — `new Promise((resolve, reject) => { /* асинхронный код */ })`.
32. **resolve(value)** — переводит Promise в состояние fulfilled.
33. **reject(error)** — переводит Promise в состояние rejected.
34. **then(onFulfilled, onRejected)** — обработка результата (возвращает новый Promise).
35. **catch(onRejected)** — обработка ошибок (короткая запись `then(null, onRejected)`).
36. **finally(onFinally)** — выполняется всегда (после resolve или reject).
37. **Цепочки then** — `promise.then(...).then(...).catch(...).finally(...)`.
38. **Возврат значения из then** — если возвращается не-Promise, оборачивается в Promise.
39. **Возврат Promise из then** — разрешается перед переходом к следующему then.
40. **Проглатывание ошибок** — ошибка в then передаётся следующему catch.

## Статические методы Promise
41. **Promise.all(iterable)** — ждёт выполнения всех Promise. Возвращает массив результатов.
42. **Promise.allSettled(iterable)** — ждёт выполнения всех Promise (независимо от статуса). Возвращает статусы.
43. **Promise.race(iterable)** — возвращает результат первого завершённого Promise.
44. **Promise.any(iterable)** — возвращает первый успешно выполненный Promise (ES2021).
45. **Promise.resolve(value)** — создаёт разрешённый Promise.
46. **Promise.reject(error)** — создаёт отклонённый Promise.
47. **Promise.try(callback)** — выполняет синхронно и оборачивает в Promise (ES2025?).

## Async/Await
48. **async function** — объявляет асинхронную функцию (всегда возвращает Promise).
49. **await** — приостанавливает выполнение до разрешения Promise.
50. **Обработка ошибок в async/await** — `try...catch` или `catch` на возвращённом Promise.
51. **await в верхнем уровне** — (ES2022) разрешён в модулях.
52. **Async стрелочные функции** — `const fn = async () => { await something(); }`.
53. **Async методы** — `class { async method() { await something(); } }`.
54. **Async генераторы** — `async function* gen() { yield await something(); }`.
55. **for await...of** — итерация по асинхронным итерируемым объектам.
56. **Параллельное выполнение в async** — `const [a, b] = await Promise.all([fn1(), fn2()])`.
57. **Последовательное выполнение** — `const a = await fn1(); const b = await fn2();`.

## Макрозадачи и микрозадачи
58. **Микрозадачи (Microtasks)** — задачи с высоким приоритетом (Promise.then, queueMicrotask, MutationObserver).
59. **Макрозадачи (Macrotasks)** — задачи с низким приоритетом (setTimeout, setInterval, I/O, UI-рендеринг).
60. **Порядок выполнения** — все микрозадачи выполняются перед следующей макрозадачей.
61. **Очередь микрозадач** — обрабатывается до рендеринга.
62. **Очередь макрозадач** — обрабатывается после полного выполнения микрозадач.
63. **Вложенные микрозадачи** — могут создавать бесконечный цикл (блокировка рендеринга).
64. **Promise.resolve().then()** — добавляет в микрозадачи.

## Обработка ошибок
65. **try...catch** — перехват синхронных ошибок.
66. **try...catch в async** — перехват ошибок в асинхронном коде.
67. **catch на Promise** — `promise.catch(error => {})`.
68. **finally на Promise** — `promise.finally(() => {})`.
69. **window.onerror** — глобальный обработчик ошибок (браузер).
70. **process.on('uncaughtException')** — обработчик непойманных ошибок (Node.js).
71. **unhandledrejection** — событие при непойманном отклонении Promise.
72. **rejectionhandled** — событие при пойманном отклонении Promise.
73. **Контекст ошибок** — сохранение стека при асинхронных операциях.
74. **Ошибки в таймерах** — ошибка в setTimeout не ловится try...catch (колбэк выполняется позже).

## AbortController и AbortSignal
90. **AbortController** — позволяет отменять асинхронные операции.
91. **AbortSignal** — сигнал для отмены (передаётся в fetch, таймеры).
92. **Создание** — `const controller = new AbortController();`.
93. **signal** — `controller.signal` для передачи в операции.
94. **abort()** — вызывает отмену (устанавливает `signal.aborted = true`).
95. **Отмена fetch** — `fetch(url, { signal: controller.signal })`.
96. **Отмена событий** — `element.removeEventListener` с тем же колбэком.
97. **Отмена таймеров** — `clearTimeout` и `clearInterval`.
98. **Кастомная отмена** — проверка `signal.aborted` в асинхронных функциях.
99. **Событие 'abort'** — `signal.addEventListener('abort', () => {})`.

## Распространённые ошибки
142. **UnhandledPromiseRejection** — непойманное отклонение Promise.

144. **Забытый await** — Promise выполняется, но результат не ожидается.
145. **Циклическая зависимость в Promise** — бесконечное ожидание.
146. **Гонка состояний (Race Condition)** — непредсказуемый порядок выполнения.
147. **Утечка памяти** — незавершённые таймеры и обработчики событий.
148. **Потеря контекста this** — передача метода без привязки.
