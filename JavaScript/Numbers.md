# Все операции с числами в JavaScript

## Арифметические операторы
1. **Сложение (`+`)** — складывает числа. Если один операнд строка — выполняет конкатенацию.
2. **Вычитание (`-`)** — вычитает числа.
3. **Умножение (`*`)** — умножает числа.
4. **Деление (`/`)** — делит числа (результат всегда число с плавающей точкой).
5. **Остаток от деления (`%`)** — возвращает остаток от деления (знак совпадает с делимым).
6. **Возведение в степень (`**`)** — возводит число в степень (например, `2 ** 3` = 8).
7. **Инкремент (`++`)** — увеличивает на 1. Постфиксный (`x++`) и префиксный (`++x`).
8. **Декремент (`--`)** — уменьшает на 1. Постфиксный (`x--`) и префиксный (`--x`).
9. **Унарный плюс (`+`)** — преобразует операнд в число (`+"123"` → 123).
10. **Унарный минус (`-`)** — меняет знак числа (`-x`).

## Операторы присваивания с арифметикой
11. **Сложение с присваиванием (`+=`)** — `x += y` → `x = x + y`.
12. **Вычитание с присваиванием (`-=`)** — `x -= y` → `x = x - y`.
13. **Умножение с присваиванием (`*=`)** — `x *= y` → `x = x * y`.
14. **Деление с присваиванием (`/=`)** — `x /= y` → `x = x / y`.
15. **Остаток с присваиванием (`%=`)** — `x %= y` → `x = x % y`.
16. **Возведение в степень с присваиванием (`**=`)** — `x **= y` → `x = x ** y`.

## Побитовые операторы (работают на 32-битных целых)
17. **Побитовое И (`&`)** — 1 если оба бита 1.
18. **Побитовое ИЛИ (`|`)** — 1 если хотя бы один бит 1.
19. **Побитовое исключающее ИЛИ (`^`)** — 1 если биты разные.
20. **Побитовое НЕ (`~`)** — инвертирует все биты (`~x` = `-(x+1)`).
21. **Левый сдвиг (`<<`)** — сдвигает биты влево (умножение на 2ⁿ).
22. **Правый сдвиг с сохранением знака (`>>`)** — сдвигает вправо с сохранением знака (деление на 2ⁿ).
23. **Правый сдвиг с заполнением нулями (`>>>`)** — сдвигает вправо, старшие биты заполняются нулями.

## Операторы сравнения чисел
24. **Больше (`>`)** — проверяет, что левое число больше правого.
25. **Больше или равно (`>=`)** — проверяет, что левое число больше или равно правому.
26. **Меньше (`<`)** — проверяет, что левое число меньше правого.
27. **Меньше или равно (`<=`)** — проверяет, что левое число меньше или равно правому.
28. **Нестрогое равенство (`==`)** — сравнивает числа с приведением типов.
29. **Строгое равенство (`===`)** — сравнивает числа без приведения типов.
30. **Нестрогое неравенство (`!=`)** — проверяет неравенство с приведением типов.
31. **Строгое неравенство (`!==`)** — проверяет неравенство без приведения типов.

## Встроенные математические методы (объект Math)
32. **Math.abs(x)** — абсолютное значение (модуль).
33. **Math.round(x)** — округление до ближайшего целого.
34. **Math.ceil(x)** — округление вверх (к большему).
35. **Math.floor(x)** — округление вниз (к меньшему).
36. **Math.trunc(x)** — отбрасывает дробную часть.
37. **Math.max(a, b, ...)** — максимальное число.
38. **Math.min(a, b, ...)** — минимальное число.
39. **Math.pow(x, y)** — возведение в степень (аналог `**`).
40. **Math.sqrt(x)** — квадратный корень.
41. **Math.cbrt(x)** — кубический корень.
42. **Math.exp(x)** — экспонента (eˣ).
43. **Math.log(x)** — натуральный логарифм (по основанию e).
44. **Math.log10(x)** — десятичный логарифм.
45. **Math.log2(x)** — двоичный логарифм.
46. **Math.sin(x)** — синус (аргумент в радианах).
47. **Math.cos(x)** — косинус.
48. **Math.tan(x)** — тангенс.
49. **Math.asin(x)** — арксинус.
50. **Math.acos(x)** — арккосинус.
51. **Math.atan(x)** — арктангенс.
52. **Math.atan2(y, x)** — арктангенс с учётом квадранта.
53. **Math.random()** — псевдослучайное число от 0 до 1.
54. **Math.sign(x)** — знак числа (-1, 0, 1).
55. **Math.clz32(x)** — количество ведущих нулей в 32-битном представлении.
56. **Math.imul(x, y)** — 32-битное умножение (для оптимизации).
57. **Math.fround(x)** — округление до 32-битного float.
58. **Math.hypot(x, y, ...)** — квадратный корень из суммы квадратов (евклидова норма).

## Числовые методы (Number)
59. **Number.isFinite(x)** — проверяет, является ли число конечным.
60. **Number.isInteger(x)** — проверяет, является ли число целым.
61. **Number.isNaN(x)** — проверяет, является ли значение NaN.
62. **Number.isSafeInteger(x)** — проверяет, что число в безопасном диапазоне (до 2⁵³).
63. **Number.parseFloat(x)** — преобразует строку в число с плавающей точкой.
64. **Number.parseInt(x, radix)** — преобразует строку в целое число (с указанием системы счисления).
65. **Number.prototype.toFixed(n)** — возвращает строку с n знаками после запятой.
66. **Number.prototype.toPrecision(n)** — возвращает строку с n значащими цифрами.
67. **Number.prototype.toExponential(n)** — возвращает строку в экспоненциальной записи.
68. **Number.prototype.toString(radix)** — преобразует число в строку в указанной системе счисления.
69. **Number.prototype.valueOf()** — возвращает примитив числа.

## Константы
70. **Number.MAX_VALUE** — максимальное положительное число (≈1.79e+308).
71. **Number.MIN_VALUE** — минимальное положительное число (≈5e-324).
72. **Number.MAX_SAFE_INTEGER** — максимальное безопасное целое (2⁵³ − 1).
73. **Number.MIN_SAFE_INTEGER** — минимальное безопасное целое (−2⁵³ + 1).
74. **Number.POSITIVE_INFINITY** — положительная бесконечность.
75. **Number.NEGATIVE_INFINITY** — отрицательная бесконечность.
76. **Number.NaN** — значение "не число".
77. **Number.EPSILON** — минимальная разница между числами (≈2.22e-16).
78. **Math.PI** — число π (≈3.14159).
79. **Math.E** — число e (≈2.71828).
80. **Math.LN2** — натуральный логарифм 2 (≈0.693).
81. **Math.LN10** — натуральный логарифм 10 (≈2.302).
82. **Math.LOG2E** — логарифм e по основанию 2 (≈1.442).
83. **Math.LOG10E** — логарифм e по основанию 10 (≈0.434).
84. **Math.SQRT2** — квадратный корень из 2 (≈1.414).
85. **Math.SQRT1_2** — квадратный корень из ½ (≈0.707).

## BigInt (для чисел больше 2⁵³)
86. **BigInt(x)** — создаёт BigInt из числа или строки.
87. **Арифметика с BigInt** — поддерживает `+`, `-`, `*`, `/`, `%`, `**` (но не смешивается с Number).
88. **Сравнение BigInt** — поддерживает `==`, `===`, `>`, `<`, `>=`, `<=`.
89. **BigInt.asIntN(bits, value)** — приводит BigInt к знаковому целому указанной длины.
90. **BigInt.asUintN(bits, value)** — приводит BigInt к беззнаковому целому указанной длины.

## Специальные операции и проверки
91. **isFinite(x)** — глобальная функция проверки на конечность (приводит тип).
92. **isNaN(x)** — глобальная функция проверки на NaN (приводит тип).
93. **parseFloat(x)** — глобальная функция для парсинга чисел с плавающей точкой.
94. **parseInt(x, radix)** — глобальная функция для парсинга целых чисел.
95. **Object.is(a, b)** — сравнивает числа (отличается от `===` для NaN и -0).
96. **Преобразование строки в число** — `Number(str)`, `+str`, `parseInt()`, `parseFloat()`.
97. **Проверка на целое число** — `x % 1 === 0` или `Number.isInteger(x)`.
98. **Проверка на чётность** — `x % 2 === 0` (чётное), `x % 2 !== 0` (нечётное).
99. **Ограничение диапазона (clamp)** — `Math.min(Math.max(x, min), max)`.
100. **Работа с -0 и +0** — `Object.is(x, -0)`, `x === 0` (не различает знак), `1/x === -Infinity` (проверка на -0).
